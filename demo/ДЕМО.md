# SVN-lite: сценарий показа (10–15 минут)

Для кого: инженеры CAD, которые работают с папками на Z: и не знакомы с SVN/Git.
Главная мысль: **«папка на Z: остаётся, но у каждого файла появляется история, откат и защита от одновременной правки»**.

Слова на показе: «хранилище» (не репозиторий), «сохранить версию» (не commit), «основной вариант» (не trunk),
«моя версия» (не branch), «занять файл» (не lock). Термины SVN не произносить.

## Подготовка (за 15 минут до показа, на своём ПК)

**Самый простой способ:** дважды щёлкните `demo\start_demo.bat`. Он каждый раз создаёт демо-сервер заново и открывает программу уже с демо-настройками (вводить ничего не нужно, пароль для входа `demo1`). Личные настройки и боевой сервер не затрагиваются. Если нужно вручную:

1. `powershell -ExecutionPolicy Bypass -File demo\start_demo_server.ps1` (повторно: с ключом `-Reset`).
   Скрипт поднимает **локальный** демо-сервер `svn://127.0.0.1:13690` во временной папке. Боевой сервер не используется.
2. Запустить SVN-lite через `start_demo.bat` (настройки подставятся сами). Вручную: F12 (Параметры) → «Общие настройки (svn_helper.json)» = путь к файлу `svn_helper.json`, который напечатал скрипт.
3. Войти как `ivanov` / `demo1` (окно входа появится само при первом обращении).
4. Открыть в Проводнике папку-«витрину» из вывода скрипта (`…\svnlite_demo\Z\Проекты_SVN`): она играет роль Z:.
5. Проверить, что TortoiseSVN установлен (кнопки «Сохранить на сервер…», «История…» видны на вкладке «Мои проекты»).

## Предупреждения

- Окна «Сохранить», «История», «Вернуть как было» — это окна TortoiseSVN, в них есть английские слова (Commit, Revert). Предупредить зал: «это стандартное окно, нужны только поле комментария и кнопка OK».
- Шаг 11 удобнее показывать со второго ПК; на одном ПК не забыть вернуться к `ivanov` и к прежней «Папке для проектов».
- Демо-сервер живёт только на этом компьютере и только пока запущен `svnserve` (после перезагрузки ПК запустить скрипт с `-Reset`).
- После показа: `demo\start_demo_server.ps1 -Stop`, затем в «Параметрах» очистить свои значения (адрес сервера, папки), иначе программа останется на демо-сервере.
- Если что-то пошло не так: «Настройки → Открыть журнал» (там полный вывод svn), окно ошибки умеет «Скопировать отчёт для администратора».
- На боевом сервере «Создать проект из папки» требует прав на запись в выбранное место хранилища; без прав программа ответит «Нет прав создавать проекты в этом месте хранилища».
