## Blocker и Major

- **Blocker. Кнопка «＋ Новый проект…» не видна** (`projects_tab.py:195-203`): ряд из трёх кнопок шире колонки 2 (`MINE_COL2_WIDTH=260`, `grid_propagate(False)`), `pack` убирает третью. Тест `test_gui_smoke.py:4148` проверяет только родителя.
- **Major. Окно откатывает живые задачи своего процесса:** `recover_create_jobs` во время сборки удалил `.creating`, создание упало с `FileNotFoundError` (подтверждено скриптом). Нужны pid и реестр активных задач ещё до CLI.
- **Major. Тупик после сбоя загрузки:** при неудачном откате журнал удаляется, на сервере остаётся пустой каркас, повтор даёт `EXISTS`.
- **Major. Пустой логин:** `author = creds.username if creds else ""`; разбор после падения не может решить, чей каркас, и журнал удаляется.
- **Major. `os.replace` журнала без повторов:** в `_bind` антивирус, держащий файл, откатывает уже успешную привязку.
- **Major. Потерянная история после переименования папки или смены диска:** единственная кнопка «Продолжить без истории» навсегда отбрасывает историю, хотя `svn relocate` её полностью возвращает (проверено). Кнопка «Отправить на сервер…» при потерянной истории скрыта, хотя отправка работает (проверено).
- **Major. Проект без истории показан как «Обычная папка, не из SVN»** с ложным советом «Скачайте проект…» (`messages.py:114`); `main_action` для `plain` возвращает None.
- **Major. «Сразу на сервер» без связи стирает собранный проект.**

## Удобство и функционал

- Нужное: шаблоны, «Сразу на сервер», восстановление после падения.
- Под вопросом: автоматическая локальная история (второе понятие «сохранения», вторая точка отказа). Вариант: по умолчанию без истории, включать галочкой в «Ещё».
- Нехватает по приоритету: восстановление потерянной истории; напоминание «проект только на компьютере N дней»; отчёт по занятым файлам; частичное скачивание; «Вернуть файл из прежнего сохранения» в «Истории» без TortoiseSVN; проверка «можно ли создавать здесь» до «Создать».
- «Сохранить у себя» и «Сохранить на сервер» человеку надо различать; при отказе `LOCAL_CHANGES` окно закрывается и отправку нужно открывать заново: лучше одним шагом «Сохранить у себя и отправить».
- Подсказка «Вход не выполнен: логин запросится сам» и серый кружок пугают: «Не подключено, пароль спросим при первом действии».
